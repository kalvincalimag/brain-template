# Planning

Use this directory for human-authored plans. Planning records are distinct from agent runtime goal databases and other runtime state.

Recommended layout:

```text
planning/
├── active/YYYY-MM-DD-<slug>.md
├── decisions/YYYY-MM-DD-<slug>.md
└── archive/YYYY/YYYY-MM-DD-<slug>.md
```

Plans should state objective, scope, acceptance criteria, dependencies, risks, verification, current status, and next action. Archive completed or abandoned plans rather than allowing the active set to become stale.
