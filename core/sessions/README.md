# Sessions

Store curated summaries of meaningful work using:

```text
sessions/YYYY/MM/YYYY-MM-DD-<slug>.md
```

Use `templates/session-summary.md`. A session file is a concise project handoff, not a raw transcript or agent rollout. Record outcomes, decisions, changed artifacts, verification, unresolved risks, next steps, and durable knowledge worth promoting.

Do not store secrets, unnecessary personal data, raw prompts, raw tool logs, or copied conversation history.
