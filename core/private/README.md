# Private

Git ignores everything in this directory except this file.

Put a full sensitive value here only when the user asks to keep it, such as a full ID number. Other files in the brain refer to it by path. Never put passwords, PINs, one-time codes, recovery codes, private keys, or access tokens here or anywhere else in the brain.

Because Git ignores this directory, its contents have no history and no backup. Losing the disk loses them.
