# Skills

Repeatable procedures specific to this brain live at:

```text
skills/<skill-name>/SKILL.md
```

A skill may keep `references/`, `scripts/`, or `assets/` beside its `SKILL.md`. Each `SKILL.md` opens with frontmatter whose `description` says when to use it. To see what exists, list `skills/*/SKILL.md` and read those descriptions.

Add a skill when you have done the same procedure twice and expect to do it again, and no global skill already covers it. Write it from what actually worked, with the date you last confirmed each step.
