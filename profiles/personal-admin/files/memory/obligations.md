# Obligations

Every recurring duty this brain tracks: filings, contributions, payments, and renewals. Each session starts by comparing `Next due` with today's date.

## Columns

- **Due rule** is how the deadline is set, such as "15th day of the month after the quarter ends". Write the rule, not only a date.
- **Next due** is the next date the rule produces. Update it after each completed record.
- **Source, checked** links the official page or issuance and gives the date it was last checked. A row without one is unverified.
- **Status** is one of: current, due soon, overdue, unverified, or paused.
