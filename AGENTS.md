# Brain template agent instructions

This repository is a template for brains. It is not a brain.

- To create a brain, follow "Create a brain" in `TEMPLATE.md`.
- To change the template, follow "Changing the template" in `TEMPLATE.md`, and run `bash tests/test-template.sh` before every commit.
- Files under `core/` and `profiles/` are the templates brains are built from. Their instructions, including `core/AGENTS.md` and `core/CLAUDE.md`, apply to brains built from them. Do not follow them while working in this repository.
- Never put facts about any brain's subject into this repository.
- Commit or push only when the user authorizes it.
